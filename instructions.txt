LOJA DE ROUPAS - INSTRUCOES DE COMPILACAO E EXECUCAO
====================================================

1. REQUISITOS
-------------
- JDK 21
- Apache Maven 3.9+ (opcional se usar IntelliJ IDEA ou NetBeans, que ja trazem o Maven embutido)
- PostgreSQL rodando em localhost:5432

2. CONFIGURACAO DO BANCO DE DADOS
---------------------------------
a) Crie o banco de dados:

   psql -U postgres -c "CREATE DATABASE loja_roupas;"

b) Crie as tabelas e dados executando o script database.sql (na raiz do projeto):

   psql -U postgres -d loja_roupas -f database.sql

c) Confira os dados de conexao em src/main/java/util/ConnectionFactory.java:

   URL     = jdbc:postgresql://localhost:5432/loja_roupas
   USUARIO = postgres
   SENHA   = 111111

   Se o usuario ou a senha do seu PostgreSQL forem diferentes, altere esses valores.

O driver JDBC do PostgreSQL (org.postgresql:postgresql:42.7.4) e baixado
automaticamente pelo Maven a partir do pom.xml.

3. COMPILACAO E EXECUCAO PELA LINHA DE COMANDO
----------------------------------------------
Na raiz do projeto (pasta onde esta o pom.xml):

   Compilar:
   mvn clean compile

   Executar:
   mvn exec:java

   Gerar o .jar (em target/):
   mvn clean package

   Executar o .jar (Windows; em Linux/macOS troque ";" por ":"):
   java -cp "target/banII_loja_roupas-1.0-SNAPSHOT.jar;%USERPROFILE%/.m2/repository/org/postgresql/postgresql/42.7.4/postgresql-42.7.4.jar" Main

4. EXECUCAO PELO INTELLIJ IDEA
------------------------------
- File > Open... e selecione o arquivo pom.xml (escolha "Open as Project").
- Aguarde o Maven baixar as dependencias.
- Abra src/main/java/Main.java e clique em Run ao lado do metodo main.

5. EXECUCAO PELO NETBEANS
-------------------------
- File > Open Project... e selecione a pasta do projeto (o NetBeans reconhece o pom.xml).
- Clique com o botao direito no projeto > Build (ou "Clean and Build").
- Clique em Run Project (F6). A classe principal (Main) ja esta configurada no pom.xml.

6. USO
------
A aplicacao roda no console e exibe um menu numerado.
Digite o numero da opcao desejada; a opcao 0 encerra o sistema.
